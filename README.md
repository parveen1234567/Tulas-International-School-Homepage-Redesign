# Tulas International School homepage

A responsive homepage redesign for Tulas International School (TIS), built with React, TypeScript, and Vite.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```sh
npm run build
npm run preview
```

The production site is generated in `dist/`. Deploy that directory with Vercel, Netlify, or GitHub Pages. For Vercel or Netlify, the default Vite build settings are:

- Build command: `npm run build`
- Output directory: `dist`

## Homepage features

- Responsive navigation with a mobile menu
- Persistent light/dark theme toggle
- Scroll progress indicator
- Scroll-triggered section reveals
- Custom pointer effect on fine-pointer devices
- Reduced-motion support

## Before publishing

Review all school-specific content and links with TIS. This concept intentionally avoids unverified performance statistics, phone numbers, and admission dates.
